
# PrintFlow

A multi-tenant SaaS platform that digitizes the print-shop workflow —
customers scan a shop's QR code, upload a document, choose print settings,
and the order lands instantly on the shop owner's dashboard. Built to
replace the common "send files over WhatsApp" workflow at local print shops.

## Tech Stack
- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL + Prisma
- Cache/Real-time: Redis, Socket.IO
- Storage: AWS S3
- Deployment: AWS EC2 (Docker), S3 + CloudFront
